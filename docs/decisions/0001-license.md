# 0001: License: PolyForm Noncommercial 1.0.0

**Status:** Accepted
**Date:** 2026-10-20

## Context
The source code should be publicly readable and usable for noncommercial purposes. The author keeps the option to offer a commercial version later, so others must not be able to commercialize the code. The repository started with GPLv3, and no code had been published under it yet.

## Options
1. **GPLv3 (initial):** open source, but it allows commercial use and hosting by anyone.
2. **AGPLv3:** also covers hosted use, but it still allows commercial use.
3. **Functional Source License (FSL):** forbids competing use; each version converts to Apache-2.0/MIT after two years.
4. **Business Source License 1.1:** a configurable restriction and change date; more to get right.
5. **PolyForm Noncommercial 1.0.0:** any noncommercial use is allowed; commercial use requires the author's permission. Short and clear.

## Decision
**PolyForm Noncommercial 1.0.0**, adopted before any application code is written.

## Consequences
- Anyone can read, run, modify, and share the code for noncommercial purposes.
- Commercial use needs a separate license from the author.
- This is not an OSI-approved open-source license. Some companies avoid such code, and outside contributions would need a contributor agreement if commercial licensing is ever offered.
